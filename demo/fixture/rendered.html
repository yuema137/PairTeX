Human Feedback in the Research Loop

A small independent fixture for Demo 1

1. Introduction

Evaluation is often treated as an endpoint. In practice, it is part of the research loop: the result changes what the agent should do next.

2. Method

The system records a human-readable feedback entry before an agent decides whether and how to update the canonical manuscript source.

feedback → agent context → canonical LaTeX change
