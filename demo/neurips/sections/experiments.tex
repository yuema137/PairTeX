\subsection{Figures with Different Aspect Ratios}

PairTeX should preserve the intrinsic aspect ratio of both portrait and wide
figures. The two images below are intentionally simple generated assets.
\begin{figure}[t]
  \centering
  \includegraphics[width=0.96\linewidth]{figures/pipeline.png}
  \caption{A synthetic model pipeline with feature, projection, activation,
  and prediction stages.}
  \label{fig:aspect-ratios}
\end{figure}

Figure~\ref{fig:aspect-ratios} is a visual regression target: the HTML view
should scale a wide, information-dense image to fit while preserving its
original proportions.

\begin{figure}[t]
  \centering
  \includegraphics[width=0.92\linewidth]{figures/pipeline.png}
  \caption{A synthetic four-stage model pipeline.}
  \label{fig:pipeline}
\end{figure}

Figure~\ref{fig:pipeline} contains labels, arrows, and several blocks. It is
intended to make it obvious when an HTML renderer drops or distorts a figure.
