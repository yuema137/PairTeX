\section{Additional Formula and Table Checks}
\label{app:checks}

The appendix provides another section boundary and another display formula.
For a positive vector $v$, consider the normalized quantity
\begin{equation}
  p_i = \frac{\exp(v_i)}{\sum_j \exp(v_j)}, \qquad \sum_i p_i = 1.
  \label{eq:normalization}
\end{equation}

The identity in Equation~\ref{eq:normalization} is included to test formula
anchors near appendix navigation. A coding agent may use the source file and
line hint from feedback to locate it, but PairTeX itself never edits this
file.
