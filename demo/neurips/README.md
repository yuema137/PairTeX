# PairTeX NeurIPS Fixture

This fixture uses the same synthetic manuscript content and generated figures
as the ICLR and ICML fixtures, with the official NeurIPS 2026 style file.
It is intended to compare renderer behavior across conference layouts.

The style file is from the official NeurIPS 2026 paper template:
<https://neurips.cc/Conferences/2026/CallForPapers>.

The fixture contains no SIDERIUS content and is not a dependency of PairTeX.
