# PairTeX ICLR Fixture

This is a small public compatibility fixture based on the official ICLR
Master-Template. It contains synthetic content and is included to exercise
PairTeX rendering of prose, citations, formulas, figures, tables, sections,
and subsections.

The template files are copied from the public ICLR Master-Template repository:
<https://github.com/ICLR/Master-Template/tree/master/iclr2026>.

This fixture is not a dependency of PairTeX and is not required by user
projects.
