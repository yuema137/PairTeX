\begin{abstract}
This public fixture exercises the basic manuscript structures that PairTeX
must render for an existing LaTeX project: prose, citations, formulas,
figures, tables, sections, and subsections. The content is synthetic and
exists only for local interaction testing.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

PairTeX presents an existing LaTeX manuscript as a readable HTML projection.
The source remains canonical, while the browser provides a convenient place
for human reading and feedback. This separation is useful when a coding agent
needs to make source-level changes across several files \citep{goodfellow2016}.

Inline mathematics such as $\alpha + \beta = \gamma$ should remain rendered
in the browser. Display mathematics written with dollar delimiters should also
be recognized:
\[
  f(x) = \int_{-\infty}^{\infty} e^{-t^2} \, dt.
\]

The same fixture deliberately uses the TeX shorthand display form:
$$
  \Pr(y \mid x) = \frac{\exp(x^\top w_y)}{\sum_{k=1}^{K}\exp(x^\top w_k)}.
$$

\section{Review Loop}
\label{sec:review}

The browser interaction is intentionally separate from source mutation. A
human may edit prose, propose a change, or attach a comment to the rendered
manuscript. PairTeX records that intent with a version and source anchor; a
user's coding agent decides how to consume it. The final source can then be
committed and rendered again.

\section{Conclusion}

This fixture is not a second document format or a replacement for the ICLR
template. It is a small public compatibility target for PairTeX's renderer
adapter and human-facing review surface.
